Comment fonctionne le stockage ?
Explication du système
📖 BENIN DOSSIER SECURE utilise votre espace cloud personnel existant (Google Drive, OneDrive ou Dropbox) comme espace de stockage réel. Vos fichiers restent dans votre compte cloud — nous enregistrons uniquement les liens de partage.
✅
Stockage illimité réel
Google Drive offre 15 GB gratuits. OneDrive 5 GB. Dropbox 2 GB. Extensibles à l'infini avec un abonnement.
🔒
Vos données vous appartiennent
Nous ne stockons ni ne téléchargeons vos fichiers. Seuls les liens de partage sont sauvegardés dans notre application.
🚀
Consultation directe
Ouvrez et consultez vos documents directement depuis l'application via les liens de partage cloud.
☁️

Comment créer un lien de partage ?
Guide étape par étape
🔵 Google Drive
1. Ouvrez drive.google.com
2. Faites un clic droit sur votre fichier
3. Cliquez sur "Partager"
4. Changez l'accès en "Toute personne avec le lien"
5. Cliquez "Copier le lien"
6. Collez ce lien dans BENIN DOSSIER
🔷 Microsoft OneDrive
1. Ouvrez onedrive.live.com
2. Cliquez sur les 3 points à côté du fichier
3. Sélectionnez "Partager"
4. Activez "Toute personne avec le lien"
5. Cliquez "Copier"
6. Collez ce lien dans BENIN DOSSIER
📦 Dropbox
1. Ouvrez dropbox.com
2. Survolez le fichier et cliquez "Partager"
3. Sélectionnez "Créer un lien"
4. Cliquez "Copier le lien"
5. Collez ce lien dans BENIN DOSSIER
